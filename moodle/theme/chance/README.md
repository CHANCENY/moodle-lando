# Chance Theme for Moodle

**Chance** is a custom theme designed to enhance the visual appeal and user experience of your Moodle platform. This theme offers a modern and responsive design, ensuring seamless access across various devices.

## Features

- **Responsive Design**: Ensures optimal viewing on desktops, tablets, and mobile devices.
- **Customizable Layout**: Easily modify the layout to suit your institution's branding and preferences.
- **Enhanced User Interface**: Improved navigation and accessibility features for a better user experience.

## Installation

To install the Chance theme on your Moodle site, follow these steps:

1. **Download the Theme**: Clone or download the Chance theme from the [GitHub repository](https://github.com/CHANCENY/moodle-lando/tree/moodle-custom-theme/moodle/theme/chance).

2. **Upload to Your Moodle Site**:
    - Extract the downloaded theme package.
    - Upload the extracted folder (named `chance`) to the `theme/` directory of your Moodle installation.

3. **Install the Theme**:
    - Log in to your Moodle site as an administrator.
    - Navigate to `Site administration` > `Notifications`.
    - Follow the on-screen instructions to complete the installation.

4. **Activate the Theme**:
    - Go to `Site administration` > `Appearance` > `Theme selector`.
    - Click on `Change theme` for the desired area (e.g., default, mobile).
    - Select `Chance` from the list of available themes.
    - Click `Use theme` to activate.

For detailed guidance on installing a new theme in Moodle, refer to the [MoodleDocs on Installing a new theme](https://docs.moodle.org/310/en/Installing_a_new_theme).

## Configuration

After activating the Chance theme, you may want to customize its settings to align with your institution's branding:

1. **Access Theme Settings**:
    - Navigate to `Site administration` > `Appearance` > `Themes` > `Chance`.

2. **Customize**:
    - Modify settings such as logos, colors, and layout options as per your requirements.
    - Save changes after configuring each section.
